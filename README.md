# JAM Kreis Linz

A community drum circle integration project connecting people through music in Linz, Austria.

## About

JAM Kreis Linz brings together diverse communities through participatory drum circles and music-making. Inspired by models like the Asheville Downtown Drum Circle, the project uses rhythm as a universal language for social integration. Designed in partnership with local integration offices and community organizations.
